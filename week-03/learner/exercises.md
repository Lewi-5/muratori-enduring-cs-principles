Complete seven programs and the notebook. General contract. Every function that reports a status returns 1 on success and 0 on rejection. **A rejected call leaves every output object unchanged**; for functions that fill several outputs, validate everything first and commit last. Output pointers are distinct from each other and from any input. A NULL output pointer is a rejection. Non-finite inputs (NaN, ±infinity) are rejected unless a prompt says otherwise. Floating-point overflow is well defined under IEC 60559 (it produces infinity); each prompt says what its function does when that happens. Do not use `errno` from math functions, do not print from library code, and do not rely on the evaluation order of function arguments: store the results of two calls in separate variables before printing them. Never rely on signed integer overflow.

Build flags are `-std=c11 -Wall -Wextra -Wpedantic -Werror -ffp-contract=off` at `-O0` and `-O2`. **`-ffast-math`, `-Ofast`, `-funsafe-math-optimizations` and `-march=native` are forbidden**: they allow reassociation and fused multiply-add and would change the numbers you are studying. Transcendental functions (`sin`, `cos`, `asin`, `atan2`, `acos`) are not required to be correctly rounded, may differ between libm versions, and their nontrivial approximations are not compared bit-for-bit; exact special values remain checked, while other tests use analytic values and the tolerances in [tests/tolerances.h](../tests/tolerances.h). Distinguish an exactly representable mathematical result (for example `sqrt(4)`), a correctly rounded but inexact result (`sqrt(2)` under Annex F), and a transcendental result assessed with a justified error tolerance. Exact comparisons apply only to selected results proved representable; correct rounding alone does not make different computational paths equal.

Reference-platform checks (E01's decomposition, the IEC 60559 relationships in E02) are gated on `__STDC_IEC_559__` with 64-bit `double` (see [support/platform.h](../support/platform.h)) and report "skipped" elsewhere. Building with `-DGEO_FORCE_NO_IEC` exercises the skip path; it does not emulate another platform.
