# Prompt-to-answer coverage

The inventory checks exact IDs, unique answer headings, valid links and source presence. Human review still evaluates reasoning quality. There are **27** prompts: 14 exercise prompts (E01.C–E07.C and E01.Q–E07.Q), 6 practice problems, 2 stretch exercises and 5 report prompts.

E04.Q contains the spherical-conversion distinction and a fully worked orthonormal basis change under its existing ID. E06.C/Q use the supplied 6,561-pair integer oracle: learners explain its independence, trace a case and add a few boundary tests rather than write another exhaustive oracle.
