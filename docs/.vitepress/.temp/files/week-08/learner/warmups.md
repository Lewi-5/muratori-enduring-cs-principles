# Warmups

### W01

Implement low_byte(word) with a mask. Test every uint16_t value. Explain why the result is independent of host byte order.

### W02

Implement replace_high(word,high) so the low byte stays unchanged. Starting with 1234 hex and high=FF, explain the result.

### W03

Implement carry8(a,b) using a widened unsigned sum. Compare 127+1 and 255+1. Does this function decide signed overflow?
