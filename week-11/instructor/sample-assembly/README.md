# Actual compiler samples — 2026-10-01

Four sets were generated by tools/inspect.py from this package's instructor and pinned support sources on x86-64 Ubuntu/WSL. GCC 11.4.0 and Clang 14.0.0 each produced debug O0 and optimized O2 output. Each manifest records the compiler, target, exact flags and source hashes; each subject has the compiler's Intel-syntax assembly and an object disassembly with relocations. Only the leading workspace directory in object-dump headers was normalized to week-11/build. Objects and executables are regenerated locally rather than stored here.

The debug/optimized files are dated observations, not required universal instruction sequences or cycle measurements. No sanitizer assembly is used as a normal-code example. DWARF 4 makes debug metadata compatible with the installed binutils; it does not select an instruction set or change the ABI. Re-run make PACKAGE=instructor CC=gcc MODE=optimized inspect (or the other compiler/mode) to compare your environment.
